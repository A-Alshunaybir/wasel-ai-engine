## Overview

The **Wasel AI Engine** is a standalone backend API built to power a smart cultural event discovery platform in Riyadh. It handles machine learning models, natural language processing, and live data manipulation to provide users with a personalized and dynamic experience.

---

## Core Architecture & Technologies

| Technology               | Description                                                                    |
| ------------------------ | ------------------------------------------------------------------------------ |
| **Framework**            | FastAPI (Python)                                                               |
| **Database Integration** | Firebase Firestore for live event data, user comments, and attendance tracking |
| **Deployment**           | Docker-based containerization for scalable cloud deployment                    |

---

## AI & Machine Learning Features

### Smart Event Recommendations

A content-based recommendation engine built with **scikit-learn** utilizing cosine similarity. Recommendations are generated by considering:

* User interests
* User ratings
* Crowd scores
* Event tags
* Live Firestore data

### Bilingual Conversational AI

Integrates **Groq LLMs** to provide a retrieval-augmented generation (RAG) chatbot featuring:

* Session memory
* Intent detection
* Bilingual interactions (Arabic and English)
* Responses grounded directly in the live event database for accurate Riyadh cultural guidance

### Live Crowd Prediction

A custom predictive system that analyzes:

* Time and seasonality
* Ticket prices
* Event categories
* Venue capacity
* Live attendance tracking

to estimate expected crowd levels for events.

### Intelligent Itinerary Generation

AI-generated tour planning that incorporates:

* GPS-based travel time estimations
* Budget-aware tour durations
* User preferences

to generate personalized bilingual itineraries.

## Project Architecture

The backend is composed of multiple AI-driven services integrated through FastAPI:

```text
API Layer (FastAPI)
        ↓
Business Logic Layer
        ↓
AI Services Layer
    ├── Recommendation Engine
    ├── Conversational AI (RAG)
    ├── Crowd Prediction
    └── Itinerary Generation
        ↓
Data Layer (Firebase Firestore)
```

This architecture promotes modularity, scalability, and ease of maintenance.
